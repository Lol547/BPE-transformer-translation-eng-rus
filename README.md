# Transformer-eng-rus-translator
Модель машинного перевода с английского на русский на основе Transformer. Самостоятельная реализация механизма внимания(seq2seq трансформера), позиционных эмбеддингов, BPE-токенизации. Обучена на датасете ManyThings (536k пар). Достигает BLEU 0.45 на тестовой выборке.
